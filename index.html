Magnus Harness

Magnus Harness is a desktop app for macOS. You chat with an AI agent that works on your Mac: it reads and edits files in the folders you choose, runs commands, and uses connected accounts, with a permission setting in each chat that decides which actions ask you first.

Why Magnus Harness asks for access to your Google data

You can connect one or more Google accounts in the app's Settings. The agent in a chat can then help with your Google data when you ask it to:

  • Google Calendar: list your calendars, find events and free time, and create, update, move or delete events and answer invitations.
  • Gmail: search and read messages and threads, create drafts, send mail, and label, archive or mark messages as read.
  • Google Drive: search and read files, and create, upload and edit files.
  • Google Photos: read only the photos you pick in Google's photo picker, upload photos and create albums.

Magnus Harness requests this access only so the agent can do these tasks for you. The app on your Mac talks to Google directly. Reads run without asking. The chat's permission setting decides whether the app asks you before each change.

Read the Privacy Policy for what Google data is accessed and how it is used, stored and shared.
